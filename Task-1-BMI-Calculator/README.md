# BMI Calculator — GUI Version

A simple desktop BMI (Body Mass Index) calculator built with Python and Tkinter.

## Features
- Clean desktop GUI with weight and height inputs
- Calculates BMI using kilograms and centimeters
- Displays BMI value and adult reference category
- Validates empty, invalid, zero, and negative inputs
- Reset button and Enter-key calculation
- Uses only Python's standard library (no pip packages required)

## Requirements
- Python 3
- Tkinter (included with most standard Windows Python installations)

## Run the project
1. Extract this folder.
2. Open a terminal in the project folder.
3. Run:

```bash
python bmi_calculator_gui.py
```

On Windows, you can also try:

```bash
py bmi_calculator_gui.py
```

## Formula
BMI = weight in kilograms / (height in meters × height in meters)

## Adult reference categories
- Below 18.5: Underweight
- 18.5–24.9: Normal weight
- 25–29.9: Overweight
- 30 and above: Obesity

BMI is a screening measure, not a diagnosis. It does not independently determine a person's health.
